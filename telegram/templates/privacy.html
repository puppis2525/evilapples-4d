Privacy Policy

Last updated November 6, 2026. This page matches the Telegram bot and the shared database. It is not a finished legal instrument. The operator still needs to confirm the legal entity, a monitored contact, a postal address, and the age rule. The address printed on the public Discord site is support@evilapples4d.com, and this repository does not prove that mailbox is monitored.

What this bot stores

  • Telegram user ids, display names, chat ids, and group titles used for games, leaderboards, and the one-time group unlock.
  • Game sessions, rounds, scores, tournament rows, and custom deck text in the shared PostgreSQL database. Telegram rows are marked with a platform column. Some user ids are stored with a tg_ prefix.
  • Stripe Checkout session ids, payment status, and the metadata needed to unlock a group or deliver a deck. Card numbers stay with Stripe.
  • Prompt text and answer text sent to Venice.ai for card generation, judging, and roasts. Those calls do not include your Telegram user id.

What it does not collect

The Telegram bot does not ask Telegram for your phone number. The Discord website login, which is separate, uses the Discord identify scope and does not request email.

Payments and retries

Webhook signatures are checked with STRIPE_WEBHOOK_SECRET. A stored event id stops the same Stripe retry from unlocking a group or granting a deck twice. Keys can be environment variables. The Replit connector is only a fallback when those variables are empty.

Age

The card text is mature. The Discord build gates gameplay to Age-Restricted channels. The Telegram bot does not have an equivalent platform age gate in code. The operator has not confirmed a legal minimum age. Do not treat this page as permission to offer the game to minors.

The longer Discord-site policy is at evilapples4d.com/privacy. Where the two disagree about implementation, the code in this repository is the source for what is stored.
